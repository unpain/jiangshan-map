# LXGW WenKai

Source: https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530

`LXGWWenKai-Regular.woff2` is a full-character-set WOFF2 conversion of the
upstream `LXGWWenKai-Regular.ttf`, made with FontTools for local web delivery.
Glyph designs and character coverage are unchanged. Both framework entries and
Canvas map labels use this font; heavier UI weights use browser synthesis.
